プライバシーポリシー

最終更新日: 2026年11月15日

「麺ウォーク - Ramen Quest」（以下「本アプリ」）は、libertya（以下「運営者」）が提供する Android 向けの散歩・ラーメン店探索ゲームです。本ポリシーは、本アプリが取得・利用する情報とその取り扱いを説明します。

2. 位置情報について

  • 位置情報は本アプリの中核機能のために利用します。権限は端末の設定からいつでも変更できます。拒否した場合、現在地に基づく機能は使えず、地図は既定の位置（東京・新宿周辺）を中心に表示されます。
  • バックグラウンドで位置情報を取得しません。
  • 移動の履歴（軌跡）を運営者のサーバーに保存しません。端末内に保存するのは、晴れた霧マスの ID（座標から決まる格子番号）と日時のみです。
  • 「店をサーチ」を実行すると、検索の中心となる緯度経度が運営者のサーバー（Supabase）に送信され、そこから Google Places API へ周辺店舗が問い合わせられます。サーバーはこの検索地点を、約 1km 四方のエリア単位のキャッシュ情報として保存します。

3. 委託先・第三者への提供

  • Supabase（データベース／サーバー機能）: 店舗検索リクエスト（検索地点の緯度経度、IP アドレスを含む通信情報）の処理と、店舗キャッシュ・利用回数・匿名プレイヤー識別子・公開用ニックネーム・拠点占領投稿（拠点名・評価・コメント）・週間ランキングスコア・通報状態の保存を委託しています。
  • Google Maps Platform（地図表示・店舗検索）: 地図表示時に端末情報・IP アドレス等が Google に送信されます。店舗検索時は、運営者のサーバー経由で検索地点と検索語が Google に送信されます。
  • Google AdMob（リワード動画広告）: 広告の配信・計測のため、広告 ID、IP アドレス、端末情報、広告の操作状況などを取得・利用します。本アプリはパーソナライズしない広告のみを要求する設定です。広告 ID は端末の設定で削除・リセットできます。

これらを除き、法令に基づく場合を除いて、取得した情報を第三者に販売・提供しません。各社の取り扱いは各社のポリシーをご確認ください。

4. 保存期間

  • 端末内のデータ: アンインストールまたはアプリのデータ消去まで保存されます。歩数は日別に直近 60 日分のみ保持します。
  • 店舗位置のキャッシュ: 取得から 7 日間を有効期間とし、期間経過後は再検索時に更新されます（place_id と座標のみを保持）。
  • 利用回数制限用の識別子・回数: 日本時間の日付ごとに集計し、不正利用防止の目的で最大 90 日間保持した後に順次削除します。
  • 拠点占領・週間ランキングのデータ: サービス提供・ランキング表示に必要な期間保持します。不適切な投稿として通報を受けたデータは直ちに非表示化され、内容が消去されます。
  • 広告関連の情報: Google のポリシーに従います。

5. 安全管理

通信は暗号化（HTTPS）されます。サーバー側のデータベースは外部から直接読み書きできないようアクセス制御を設定しています。ただし、完全な安全性を保証するものではありません。

6. 子どもについて

本アプリは 13歳未満の方を対象としていません。運営者は 13 歳未満の子どもから意図して個人情報を収集しません。お子さまの情報が提供されたと思われる場合は、下記の連絡先までご連絡ください。
